## What it is for
Every department at once, ranked so the one needing attention is obvious.

## Who can see it
Administrators.

## The three things people do here
1. Read the organisation KPIs — open tasks, overdue, SLA compliance, open alerts.
2. Sort the department table by SLA % to find the weakest.
3. Drill into a department.

## Common confusions
- "Two departments show the same percentage but different colours." The colour follows the trend, not just the value.
