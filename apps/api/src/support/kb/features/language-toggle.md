## What it is for
Every screen, label, message and error is available in both English and Hindi.

## How to use it
The EN / हिंदी control sits in the top bar. The choice is remembered.

## Common confusions
- "The toggle is unclickable during a tour." The tour overlay blocks the page behind it on purpose, so the language control is repeated inside the tour card itself.
- "Some names stayed in English." People's names, reference numbers and department codes are not translated — only the interface is.
