## What it is for
The first screen an employee sees. It answers one question: what should I do next?

## Who can see it
Employees. Managers and Administrators have their own dashboards.

## The three things people do here
1. Read **Today's Focus** — the open tasks nearest their deadline, most urgent first. Completed work is deliberately excluded; this list is about what is still owed.
2. Check the counters — assigned, due today, overdue, and this month's completion rate.
3. Click straight through to a task to add progress.

## Common confusions
- "My dashboard is empty." If *everything* is empty rather than just Today's Focus, the account probably has no department set — see USER_NO_DEPARTMENT.
- "A task I finished is still showing." Finishing is not the same as being approved. Work you submit sits in Under review until a manager accepts it.
