How it is built

Open-source throughout — licensing cost zero

Web application
What officers see — dashboards, task board, reports. English and हिंदी.
Next.js · TypeScript

Interface layer
The rulebook — who may see what, and which transitions are permitted. Over forty documented endpoints.
Node.js · Express
3
Database and audit chain
A standard relational database. Every change sealed into a linked block in the same transaction.
PostgreSQL · SHA-256
4
Analytical service
Morale, workload and anomaly scoring. Runs offline — if it stops, the interface layer computes the same values.
Python · FastAPI
Deployable on NIC Cloud or any government-approved environment
